<h1 align="center">Arkea</h1>

<p align="center">A client-side interface library for Minecraft mods with animated, consistent settings screens.</p>

## Requirements

| | |
|---|---|
| Minecraft | 26.3 |
| Loader | NeoForge 26.3.0.51-beta or newer |
| Java | 25 |
| Side | Client only |

```
./gradlew build
```
