# Support for Arkea

Need help with Arkea or encountered a problem? Here is how to get support.

## Getting Help

- **Documentation & Features:** Check the [Arkea Feature Guide](docs/FEATURES.md).
- **Developer Documentation:** Check the [Arkea API Guide](docs/API.md).
- **Issue Tracker:** If you found a bug or have a suggestion, search existing issues first on our [GitHub Issues](https://github.com/arystonmc/Arkea/issues).

## Reporting Bugs

When filing an issue, please include:
1. Minecraft version, NeoForge version, and Arkea version.
2. Other installed mods (if relevant).
3. The latest game log file (`logs/latest.log`) uploaded via a paste service like [mclo.gs](https://mclo.gs).
4. Steps to reproduce the problem and screenshots or video clips if relevant.

Please use our structured [Bug Report Template](https://github.com/arystonmc/Arkea/issues/new?template=bug_report.yml).
